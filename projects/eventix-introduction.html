What the app is for

  • Lets students discover and filter Tech, Sports, and Cultural school events
  • Provides organization profile pages for groups such as Code Hex and Kassimpa Squad
  • Shows organization member counts and hosted events in one directory
  • Creates digital passes with unique ticket identifiers and simulated QR codes
The goal of Eventix is to make campus events easier to find, organize, and attend through a clear mobile-first ticketing experience.

Booking and payment flow

From the dashboard, users select an event, adjust ticket quantity, review a booking summary, choose a payment method, and receive confirmation. Active tickets remain available through the bottom navigation.

  • Supports GCash, credit card, and over-the-counter transactions
  • Calculates a 5% service fee automatically
  • Displays a booking confirmation and digital ticket after the mock transaction

Technical architecture

The application uses a responsive 430px layout container to emulate a native mobile app. A centralized client-side JavaScript state object powers dynamic template-rendering functions across discovery, booking, payment, and ticket management screens. The interface uses modern CSS custom properties, Flexbox, Boxicons, and a dark navy-and-gold visual system.
